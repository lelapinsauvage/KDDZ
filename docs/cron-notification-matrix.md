# Cron And Notification Restoration Matrix

Legacy cron and notification behavior has two separate surfaces:

- Scheduled generators that create in-app alarm rows and delivery/read rows.
- Mobile push delivery through OneSignal player IDs stored in `notifications_tokens`.

Historical rows from `t_alarms*`, `custom_notifications*`, `notifications_tokens`, `t_notifications_log`, and `notifications_nature` are migrated by `src/scripts/migration/migrate-alarms.ts`. Local approved generator jobs, manual actions, and protected cron-safe endpoints are restored; the remaining acceptance work is hosted scheduler cutover, provider-backed external delivery, native-device execution, and production `notifications_nature` validation.

## Research Standard

Benchmarks are studied for decisions, not aesthetics alone. Each product is evaluated across:

- How it reveals a broad feature set.
- How users understand current state and next action.
- How navigation changes with context.
- How dense information remains readable.
- How creation, editing, undo, and recovery work.
- How motion explains continuity and completion.
- How brand character survives inside utility screens.
- How desktop, web, and iOS experiences remain related without becoming identical.

## Named Product Benchmarks

### Revolut

**Evidence:** [Revolut Product and Design](https://www.revolut.com/careers/team/product-design/)

Revolut describes its design work as turning complex problems into simple, elegant, data-driven experiences, with product and design owning work from concept through launch and refinement.

**Study:** Home hierarchy, contextual actions, financial confidence, progressive disclosure, onboarding, status, receipt/confirmation, and recovery.

**Kiddz transfer:** Treat each nursery workflow as a complete lifecycle. A payment, attendance mark, medical record, or ratio intervention needs entry, validation, confirmation, history, and recovery.

**Reject:** Promotional home modules, fintech visual metaphors, and complexity hidden so deeply that operational evidence becomes hard to find.

### Notion

**Evidence:** [Updating the design of Notion pages](https://www.notion.com/en-gb/blog/updating-the-design-of-notion-pages)

Notion's 2026 page refresh standardizes rhythm while changing spacing according to adjacent content. Lists remain compact; prose receives more air. The result is systematic without forcing every block into identical spacing.

**Study:** Content-first composition, inline actions, adjacency, block rhythm, contextual menus, progressive detail, flexible objects.

**Kiddz transfer:** Density is contextual. A child record list, form section, narrative note, and action queue should share tokens but not identical spacing.

**Reject:** Blank-canvas assumptions and neutral styling that erases Kiddz personality or operational urgency.

### Cursor

**Evidence:** [Cursor product](https://cursor.com/)

Cursor's current public product demonstrates explicit work states such as In Progress and Ready for Review, parallel tasks, command-driven entry, contextual artifacts, end-to-end agent work, and spring/shared-element transitions in its Mission Control concept.

**Study:** Desktop density, keyboard flow, command architecture, multi-pane continuity, task queues, progress, review state, and autonomy controls.

**Kiddz transfer:** Nursery work also moves through queued, active, blocked, ready-for-review, and handled states. The manager needs an operational queue, not a wall of badges.

**Reject:** IDE density, developer language, dark-only surfaces, and panels that require expert spatial memory.

### Cosmos

**Evidence:** [Cosmos](https://www.cosmos.so/) and [Cosmos on the App Store](https://apps.apple.com/us/app/cosmos-search-discover/id1577975475)

Cosmos emphasizes connected collections, search by color and visual similarity, AI-content controls, provenance, and a visually quiet discovery experience across web and iOS.

**Study:** One-tap capture, search modes, curation, content provenance, collection context, collaboration, and low-noise navigation.

**Kiddz transfer:** Search should match how nursery users think: child, parent, room, branch, status, date, or action. Records should expose source and history without cluttering the first scan.

**Reject:** Image-led layouts where names, status, dates, audit data, or urgent exceptions must lead.

### Vercel / Geist

**Evidence:** [Geist Design System](https://vercel.com/geist/introduction)

Geist explicitly treats grid as a major aesthetic foundation and provides high-contrast accessible color, purpose-built typography, icons, and a deep component vocabulary including command menus, destructive-action modals, entities, feedback, status, tables, and empty states.

**Study:** Grid discipline, token depth, type hierarchy, state components, command patterns, and consistent geometry.

**Kiddz transfer:** Build a complete operational vocabulary, including the unglamorous states. Precision is the base on which expressive Kiddz moments sit.

**Reject:** Monochrome austerity and developer-product coldness.

### Duolingo

**Evidence:** [Duolingo Brand Guidelines](https://design.duolingo.com/) and the user's saved logo-motion reference.

Duolingo maintains one documented system across identity, imagery, writing, character, and product expression. The public-board reference highlights that its logo can act like a character while remaining recognizable.

**Study:** Brand family, character rules, voice, color ownership, progress, celebration, error recovery, onboarding, and motion timing.

**Kiddz transfer:** Build a recognizable brand world with strict usage roles. Positive care completion can feel satisfying; routine work can feel lighter; difficult messages can feel human.

**Reject:** Streak anxiety, gamified safeguarding, manipulative retention, and mascot presence in every state.

### Duolingo ABC

**Evidence status:** Mobile flow capture pending.

**Study:** Child-safe interaction, guided progression, instruction without reading dependence, large targets, audio/visual reinforcement, and guardian trust.

**Kiddz transfer:** Useful for practitioner and parent guidance, not as the visual model for the desktop manager application.

### Genie iOS

**Evidence:** [Genie on the App Store](https://apps.apple.com/us/app/chatbot-ai-assistant-genie/id1658377526)

**Study:** Conversational entry, quick actions, media states, model/tool choice, progress, history, and multimodal results.

**Kiddz transfer:** Natural-language search may become a secondary shortcut for records and reports, but structured high-risk actions remain explicit.

**Reject:** A universal chat box replacing forms, permissions, or auditable workflows.

### Anything web and iOS

**Evidence:** [Anything Mobile](https://www.anything.com/app)

Anything presents cross-device creation: projects appear on mobile, voice can replace typing, web and native previews coexist, and the user can start on one device and continue on another.

**Study:** Cross-device handoff, voice input, creation progress, preview, project history, and return-to-work.

**Kiddz transfer:** A practitioner should be able to start a record on tablet or mobile and finish it on desktop without losing state or context.

**Reject:** Generated-interface inconsistency and opaque automated changes.

## Cross-Benchmark Principles Emerging

1. **State is an object.** Strong products make work status visible and actionable, not implicit in counts.
2. **Density follows content.** Notion-like rhythm and Vercel-like geometry create consistency without universal card padding.
3. **A broad product needs more than navigation.** Revolut, Cursor, and Cosmos use context, search, recents, queues, and progressive detail.
4. **Brand character is governed.** Duolingo, Headspace, Klarna, and LEGO are expressive because usage is systematic, not random.
5. **Motion preserves continuity.** Shared context, completion, reordering, and return-to-work benefit from motion; routine repetition does not.
6. **The product must explain consequence.** Financial and operational leaders show what changed, what is pending, and what the user can do next.
7. **Cross-device means workflow continuity.** It is not the same layout scaled down.
